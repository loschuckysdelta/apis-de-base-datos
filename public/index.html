✅ Verificación de Telegram

La API /api/verificar registra la confirmación de visita de usuarios existentes y permite consultar su estado en MongoDB. No pide token de Telegram. La API de usuarios sigue sin cambios.

Uso: La página envía {"telegramId":"123456789"} a POST /api/verificar. La API registra el estado durante 24 horas; GET /api/verificar?telegramId=... permite consultar si sigue activo.

Importante: sin una prueba de identidad, el ID es solo un identificador declarativo y no acredita la propiedad de la cuenta. Para antirobots reales, habilita Turnstile. Consulta VERIFICAR-API-INSTRUCCIONES.md.
